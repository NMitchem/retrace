# retrace M1 — General Memory-Diff Syscall Recorder — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace M0's hand-written `write`/`exit` handlers with a general recorder that captures any syscall's effects by memory-diff + pointer-chasing, proven on a static MMU-off file-I/O guest that replays byte-for-byte after its input file is deleted.

**Architecture:** The guest still runs at EL0, MMU off (guest VA == IPA), in the M0 box. On a syscall trap the recorder pointer-chases the argument registers, snapshots a window around each guest pointer, forwards the real syscall to the host kernel (translating guest pointers to host backing addresses), and diffs to find what the kernel wrote — logged as `writes: Vec<Region>`. Replay applies the recorded writes and feeds the recorded return value without executing anything. A final full-guest-memory comparison at exit is the oracle for the engine. `mmap` is special-cased (it creates a new tracked backing); `munmap`/`mprotect` write no guest memory and are recorded no-ops.

**Tech Stack:** Rust 1.95, Hypervisor.framework via the in-tree `hv-sys` crate, `libc::syscall` for host forwarding (record only), `clang` for the guest.

## Global Constraints

- **Platform:** Apple Silicon, macOS 26.x. Target `aarch64-apple-darwin`. Builds on M0 (merged to `main`); all M0 tests must stay green.
- **Entitlement:** every `hv_*`-calling binary is ad-hoc codesigned with `com.apple.security.hypervisor` via the `.cargo/config.toml` runner. A binary spawned by a test (`CARGO_BIN_EXE_*`) bypasses that runner and must be codesigned in the test helper (see `crates/retrace/tests/e2e.rs::bin()`).
- **One VM per process.** In-process VM tests create at most one VM per test; run VM tests with `--test-threads=1`. End-to-end record→replay tests drive the `retrace` CLI as separate subprocesses.
- **MMU off in M1.** Guest VA == guest IPA; the host backing lives at an unrelated host address. A guest pointer `p` maps to host address `backing.host + (p - backing.ipa)`. Pointer args passed to a forwarded syscall MUST be translated to host addresses; scalar args pass through unchanged.
- **No syscall executes during replay** (negative-space invariant, asserted): replay applies recorded `writes` and feeds recorded `ret`; it never calls `libc::syscall`.
- **Determinism discipline:** no wall-clock/OS-RNG/threads in core crates (clippy deny-list enforced). `libc` is allowed in `retrace-box` (it owns the unsafe/HVF/host-forwarding layer); `retrace-core` must NOT depend on `hv_sys` or `libc` after Task 1 — it is pure orchestration + trace + divergence logic.
- **Assertions stay on in release** (`assert!`, not `debug_assert!`). Error/divergence messages name the contract, the site, and the fix, and print the seed + a one-command repro.
- **M1 assumes successful syscalls.** The macOS raw-syscall error ABI (carry flag set, `x0` = errno) is NOT modeled in M1 — the guest and fixtures are constructed so every syscall succeeds. `libc::syscall`'s POSIX return (positive result on success) is what the guest's `x0` receives. Error-ABI fidelity is deferred (documented, not silently assumed).
- **Syscall numbers (macOS arm64 BSD, in `x16`, `svc #0x80`):** `exit=1, read=3, write=4, open=5, close=6, munmap=73, mprotect=74, fstat=189, mmap=197, lseek=199`.
- **License:** MIT OR Apache-2.0; clean-room.

```rust
    pub fn open_checked<P: AsRef<Path>>(path: P) -> io::Result<(Vec<Event>, bool)> {
        let mut buf = Vec::new();
        File::open(path)?.read_to_end(&mut buf)?;
        if buf.len() < 4 || buf[0..4] != TRACE_MAGIC {
            return Ok((Vec::new(), true)); // wrong/absent magic: reject loudly, keep nothing
        }
        let mut out = Vec::new();
        let mut off = 4usize;               // skip the 4-byte header
        let mut truncated = false;
        while off + 8 <= buf.len() {
            let len = u32::from_le_bytes(buf[off..off+4].try_into().unwrap()) as usize;
            let crc = u32::from_le_bytes(buf[off+4..off+8].try_into().unwrap());
            let start = off + 8;
            if start + len > buf.len() { truncated = true; break; }
            let body = &buf[start..start+len];
            if crc32(body) != crc { truncated = true; break; }
            match bincode::deserialize::<Event>(body) {
                Ok(e) => out.push(e),
                Err(_) => { truncated = true; break; }
            }
            off = start + len;
        }
        if off != buf.len() { truncated = true; }
        Ok((out, truncated))
    }
```

The guest logic:
```asm
.section __TEXT,__text
.global _start
.p2align 2
_start:
    // open(path, O_RDONLY=0, 0)
    adrp x0, path@PAGE
    add  x0, x0, path@PAGEOFF
    mov  x1, #0                 // O_RDONLY
    mov  x2, #0
    mov  x16, #5                // SYS_open
    svc  #0x80
    mov  x19, x0                // save fd

    // fstat(fd, statbuf)  -- exercises a struct-write memory-diff
    mov  x0, x19
    adrp x1, statbuf@PAGE
    add  x1, x1, statbuf@PAGEOFF
    mov  x16, #189              // SYS_fstat
    svc  #0x80

    // read(fd, buf, 19)   -- the money case: kernel writes file bytes into buf
    mov  x0, x19
    adrp x1, buf@PAGE
    add  x1, x1, buf@PAGEOFF
    mov  x2, #19               // fixture length "retrace-m1-fixture\n"
    mov  x16, #3               // SYS_read
    svc  #0x80
    mov  x20, x0               // nbytes read

    // write(1, buf, nbytes)  -- emit what we read
    mov  x0, #1
    adrp x1, buf@PAGE
    add  x1, x1, buf@PAGEOFF
    mov  x2, x20
    mov  x16, #4              // SYS_write
    svc  #0x80

    // close(fd)
    mov  x0, x19
    mov  x16, #6             // SYS_close
    svc  #0x80

    // exit(0)
    mov  x0, #0
    mov  x16, #1
    svc  #0x80

.section __DATA,__data
.p2align 4
buf:      .space 64
statbuf:  .space 256
// `path:` is appended by the build script (generated) so it matches the fixture location.
```

Add to `crates/retrace-box/src/lib.rs` (inside `impl Box_`), and add `pub const PTR_WINDOW_CAP: usize = 64 * 1024;` near the other consts:
```rust
    // Translate a guest IPA to (host pointer, bytes available to the end of its backing).
    fn host_span(&self, ipa: u64) -> Option<(*mut u8, usize)> {
        for bk in &self.backings {
            if ipa >= bk.ipa && ipa < bk.ipa + bk.len as u64 {
                let off = (ipa - bk.ipa) as usize;
                return Some((unsafe { bk.host.add(off) }, bk.len - off));
            }
        }
        None
    }

    /// Record-side memory-diff. For each arg that points into a mapped region, snapshot a
    /// window (capped) and translate it to a host address; forward the real syscall; diff.
    /// M1 assumes the syscall succeeds (see plan's error-ABI note).
    pub fn forward_and_diff(&self, num: u64, args: [u64;7]) -> (u64, Vec<Region>) {
        let mut windows: Vec<(u64, usize, Vec<u8>)> = Vec::new(); // (guest_ipa, len, pre-image)
        let mut hargs = [0i64; 7];
        for i in 0..7 {
            match self.host_span(args[i]) {
                Some((hp, avail)) => {
                    let win = avail.min(PTR_WINDOW_CAP);
                    let pre = unsafe { std::slice::from_raw_parts(hp, win) }.to_vec();
                    windows.push((args[i], win, pre));
                    hargs[i] = hp as i64;
                }
                None => hargs[i] = args[i] as i64,
            }
        }
        let ret = unsafe {
            libc::syscall(num as libc::c_long, hargs[0], hargs[1], hargs[2],
                          hargs[3], hargs[4], hargs[5], hargs[6])
        } as u64;
        let mut writes = Vec::new();
        for (ipa, len, pre) in windows {
            let (hp, _) = self.host_span(ipa).unwrap();
            let post = unsafe { std::slice::from_raw_parts(hp, len) };
            if post != pre.as_slice() {
                writes.push(Region { ipa, bytes: post.to_vec() });
            }
        }
        (ret, writes)
    }

    /// Replay-side: apply recorded writes to guest memory, then resume. Never executes a syscall.
    pub fn apply_and_return(&mut self, ret: u64, writes: &[Region]) {
        for w in writes {
            let (hp, avail) = self.host_span(w.ipa)
                .unwrap_or_else(|| panic!("apply_and_return: write ipa {:#x} outside any mapped region", w.ipa));
            assert!(w.bytes.len() <= avail,
                "apply_and_return: write at {:#x} ({} bytes) overruns backing ({} avail)", w.ipa, w.bytes.len(), avail);
            unsafe { std::ptr::copy_nonoverlapping(w.bytes.as_ptr(), hp, w.bytes.len()); }
        }
        self.set_x0_and_return(ret);
    }

    /// Compare current guest memory against `expected`; return the first divergence, or None.
    pub fn diff_memory(&self, expected: &[Region]) -> Option<String> {
        for r in expected {
            let (hp, avail) = match self.host_span(r.ipa) {

                    "memory divergence at ipa {:#x}: replay=0x{:02x} recorded=0x{:02x}",
                    r.ipa + off as u64, cur[off], r.bytes[off]));

    }
```

## M1 → M2 boundary

M2 is the loader — MMU-on guest page tables, standalone `dyld` startup with pointer authentication (PAC), and the dyld-shared-cache loader — so a real dynamically-linked binary (a normally-compiled C program linking `libSystem`) loads and runs. **M2 gets an HVF-style verification spike before its design is finalized** (mirroring M0's pass): confirm PAC works in the guest, locate and map the arm64e system DSC, and prove a minimal MMU-on page-table walk. The memory-diff engine, trace format, divergence oracle, and seeded swarm from M1 carry forward unchanged; the pointer-chase window policy (`PTR_WINDOW_CAP`) and the error-ABI handling will need revisiting once real programs (large mappings, failing syscalls) are recorded.

- **`forward_and_diff` write-extent risk (memory-safety boundary, not just a fidelity gap):** `forward_and_diff` passes guest-controlled size/count args unchanged to the forwarded host syscall, so during record a `read(fd, buf, count)` with `count` larger than `buf`'s backing allocation would have the host kernel write past that backing. Unreachable in M1 (trusted guests, small counts, record isn't fault-injected), but before M2 records untrusted/large I/O this needs an explicit clamp/assert that the write extent fits the backing.

## Self-Review notes (author)

- **Spec coverage:** general memory-diff recorder (T4/T5/T6), pointer-chasing (T4 `forward_and_diff`), special-cased mmap/munmap/mprotect (T7), final full-memory oracle (T6 `diff_memory`), file-I/O guest + fixture (T3), box↔core encapsulation (T1), trace-format evolution + version (T2), seeded swarm (T8). Every spec section maps to a task.
- **Honest scoping deviation from the spec:** the spec lists mmap/munmap/mprotect as "special cases"; the plan implements only `mmap` as a map-creating special case and records `munmap`/`mprotect` as no-ops, because in M1 (MMU-off, trusted guest, no address reuse) they write no guest memory and honoring them is unnecessary. This is documented in T7 and the README; honoring them is deferred to M2.
- **Type consistency:** `Event::Syscall` gains `writes: Vec<Region>` in T2 and every producer/consumer (T5 record, T6 replay, T7 mmap, T8 swarm) uses that shape. `Box_` accessors `snapshot`/`position`/`pc`/`forward_and_diff`/`apply_and_return`/`diff_memory`/`guest_mmap` are defined before use. `retrace-core` uses only `retrace_box`/`retrace_trace`/`retrace_arch` after T1 (no `hv_sys`/`libc`).
- **Known execution risks (not placeholders):** (a) a scalar syscall arg that coincidentally falls in a mapped region would be mis-translated to a host pointer — unreachable for M1's guests (fds/lengths/flags are small and outside the mapped ranges), caught by divergence if it ever happens; (b) `libc::syscall` variadic call must pass all 7 args as `c_long` — if a toolchain rejects the 7-arg form, pass the 6 the macOS ABI uses; (c) M0 `replay.rs` tests may need their event-count expectations updated for the trailing final Snapshot (T6 Step 4); (d) the fileio fixture is a shared build artifact and the "replay after delete" test (T6) deletes then restores it — a low-probability cross-binary race with other fixture-reading test binaries (cargo parallelizes test binaries; `--test-threads=1` only serializes within a binary). The test restores the fixture; if flakes appear, guard fixture-mutating tests with a lock file. Same class as M0's documented `replay.rs` parallelism caveat.
- **Dispatch-arm order (T5+T7):** the `match b.run()` arms must be `EXIT` / `MMAP` / `MUNMAP|MPROTECT` / `WRITE-to-fd-1/2` (all guarded, mutually exclusive) BEFORE the general `Stop::Syscall { num, args } =>` catch-all, which then handles exactly the data syscalls (`read`/`open`/`close`/`fstat`/`lseek`) via `forward_and_diff`. Rust matches first-to-last; the catch-all must be last.

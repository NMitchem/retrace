# retrace M2 — The Loader (MMU-on, dyld, PAC, shared cache) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get a normally-compiled, dynamically-linked C program running inside the box by letting *real dyld* load it, and record + replay it with zero divergence — MMU on, PAC on, the shared cache mapped by dyld itself.

**Architecture:** retrace-box emulates only the kernel's process-setup contract: build a guest-side identity stage-1 page-table map (MMU on, Normal memory), set fixed PAC keys, map the main Mach-O and `/usr/lib/dyld` (arm64e) into **anonymous** guest pages, build the initial stack (`argc/argv/envp/apple[]`, `DYLD_SHARED_REGION=private`), and jump to dyld's entry. Real dyld then maps the dyld shared cache itself via ordinary `open`/`mmap`/`pread` syscalls, which the M1 memory-diff recorder already traps and forwards. We write no shared-cache parser. The M1 trace format, divergence oracle, and seeded swarm carry forward; M2 pays the four recorder debts M1 deferred.

**Tech Stack:** Rust 1.95, Hypervisor.framework via the in-tree `hv-sys` crate, a raw `svc #0x80` shim for host syscall forwarding (record only), `clang` for guests, real system `/usr/lib/dyld` + dyld shared cache.

## Global Constraints

- **Platform:** Apple Silicon, macOS 26.x (spike host: 26.4.1 / build 25E253). Target `aarch64-apple-darwin`. Builds on M1 (merged to `main`); **all M1 tests must stay green after every task**.
- **Entitlement:** every `hv_*`-calling binary is ad-hoc codesigned with `com.apple.security.hypervisor` via the cargo runner (`tools/codesign-run.sh`). A test-spawned `CARGO_BIN_EXE_*` binary must be codesigned in the test helper (see `crates/retrace/tests/e2e.rs::bin()`).
- **One VM per process.** In-process VM tests create at most one VM per test; run VM tests with `--test-threads=1`. End-to-end record→replay tests drive the `retrace` CLI as separate subprocesses.
- **SPTM HARD RULE (load-bearing, learned the hard way — see spike):** NEVER `hv_vm_map` a file-backed page. On macOS 26 that hard-panics the machine (`[SPTM] VIOLATION_ILLEGAL_MAPPING_TYPE`). All guest memory is **anonymous** (`MAP_ANON`); file bytes (dyld, the cache, the executable) are read/`pread`/`fread` into anon pages, and those anon pages are mapped. This is why every `hv_vm_map` in the codebase targets an anon buffer; keep it that way.
- **Identity VA==IPA preserved.** MMU is on, but the stage-1 map is identity (guest VA == IPA), so M1's pointer arithmetic (`host = backing.host + (guest_ptr - backing.ipa)`) is unchanged and forwarded-syscall pointers stay valid. Stage-1 permissions are **W^X** (writable⇒non-exec, exec⇒read-only) — mandatory: executing from a writable guest page hangs the vCPU on this host (Apple-Silicon W^X; see Task 2). The security boundary remains stage-2 + the VMM, exactly as in M1.
- **Fixed PAC keys.** The five pointer-authentication key registers are set to compile-time constants, identical on record and replay, so pointer signing is deterministic. Keys live in `retrace-box` as named consts.
- **No syscall executes during replay** (negative-space invariant): replay applies recorded `writes`, feeds recorded `ret`, and restores the recorded carry flag; it never issues an `svc`. `retrace-core` still must NOT depend on `hv_sys`/`libc`.
- **Assertions stay on in release** (`assert!`, not `debug_assert!`). Divergence/abort messages name the contract, the site, and the fix, and print the seed + a one-command repro.
- **Syscall numbers (macOS arm64 BSD, in `x16`, `svc #0x80`):** existing M1 set plus `mmap=197` (already), and mach traps arrive as negative syscall numbers (`x16 < 0`, e.g. `mach_reply_port=-26`, `task_self_trap=-28`, `_kernelrpc_mach_vm_map_trap=-71`); M2 discovers exactly which are needed in Task 9.
- **License:** MIT OR Apache-2.0; clean-room. Real dyld and the cache are loaded, never copied into the repo.

### Task 2: MMU on — guest **W^X** identity stage-1 page tables

Replace M0/M1's MMU-off setup with a guest-built **identity** stage-1 map (guest VA == IPA). **CRITICAL PLATFORM CONSTRAINT (verified the hard way, 2026-07-06):** on this host you **cannot execute from a writable page** — a stage-1 page that is both writable and executable makes instruction fetch fault into an unrecoverable loop that **hangs `hv_vcpu_run` forever** (the same Apple-Silicon W^X rule that forces JIT to use `MAP_JIT`). So the map MUST be **W^X**: writable regions are non-executable, executable regions are read-only. The spike (`spikes/m2spike.c`) proves this exact separation works on this host; a uniform RWX map does NOT. Then in `crates/retrace-box/src/lib.rs` add the constants, the W^X table builder, and wire `load`/`restore`:
```rust
pub const PT_L2_IPA:  u64 = 0x8000;           // L2 table (TTBR0 target); one 16 KiB page = 2048 entries
// L3 tables live in a reserved band inside block 0 (8-32 MiB), well above trampoline/PT_L2/stack
// (all < 128 KiB) and below the 32 MiB block boundary — room for ~1500 L3 tables. Keeping them in
// block 0 (already L3-promoted for the trampoline) means they're data-covered by block 0's own L3.
pub const PT_L3_BASE: u64 = 0x0080_0000;      // 8 MiB; bump by GRANULE per promoted block
const PT_L3_CEIL:     u64 = 0x0200_0000;      // 32 MiB block boundary — assert next_l3 stays below
const TCR_EL1_V:  u64 = 0x1_0080_B51C;        // T0SZ=28, TG0=16K, WBWA, inner-share, EPD1, IPS=36-bit (spike-proven)
const MAIR_EL1_V: u64 = 0xFF;                 // attr0 = Normal WBWA
// base 0x30d00800 + M(1) + C(4) + I(0x1000). PAC enable bits are added in Task 3.
const SCTLR_MMU_ON: u64 = 0x30d0_0800 | 1 | 4 | 0x1000;

// Descriptor low/high attribute bundles (without base address or type bits). AF|SH-inner|AttrIndx0,
// then AP + execute-never bits. W^X: data is writable+non-exec; code/tramp are read-only+exec.
const A_COMMON: u64 = 0x400 /*AF*/ | 0x300 /*SH inner*/;   // AttrIndx 0 = Normal WBWA
const UXN: u64 = 1 << 54;                     // unprivileged (EL0) execute-never
const PXN: u64 = 1 << 53;                     // privileged (EL1) execute-never
const ATTR_DATA:  u64 = A_COMMON | 0x40 /*AP EL0RW*/ | UXN | PXN;   // RW, never executable
const ATTR_CODE:  u64 = A_COMMON | 0xC0 /*AP RO both ELs*/ | PXN;   // RO, EL0-exec (UXN clear), EL1 no-exec
const ATTR_TRAMP: u64 = A_COMMON | 0x80 /*AP EL1-RO, EL0 none*/ | UXN; // RO, EL1-exec (PXN clear)
const DESC_BLOCK: u64 = 0x1;                  // L2 block descriptor
const DESC_TABLE: u64 = 0x3;                  // L2 -> L3 table descriptor
const DESC_PAGE:  u64 = 0x3;                  // L3 page descriptor
const BLK: u64 = 1 << 25;                     // 32 MiB per L2 entry

impl Box_ {
    // W^X identity stage-1 map. Default: every 32 MiB L2 entry is a data BLOCK (RW, non-exec) —
    // covers stack/data/heap/mmap-data and identity-covers the whole 36 GiB space. Each exec range
    // (ipa,len,attr) gets page-granularity pages with `attr`; its covering block(s) are promoted to
    // an L3 table (identity-filled with ATTR_DATA, then exec pages overwritten). Returns PT_L2_IPA.
    // Pushes the L2 + every L3 as backings; the caller stage-2-maps them. NEVER file-backed (SPTM).
    fn build_tables(backings: &mut Vec<Backing>, exec: &[(u64, u64, u64)]) -> u64 {
        let (l2_host, l2_len) = alloc_pages(GRANULE);
        let l2 = unsafe { std::slice::from_raw_parts_mut(l2_host as *mut u64, 2048) };
        for (i, e) in l2.iter_mut().enumerate() { *e = ((i as u64) * BLK) | ATTR_DATA | DESC_BLOCK; }
        backings.push(Backing { host: l2_host, ipa: PT_L2_IPA, len: l2_len });

        // Which 32 MiB blocks contain an exec range? (sorted, deduped)
        let mut blocks: Vec<u64> = exec.iter()
            .flat_map(|&(va, len, _)| (va / BLK)..=((va + len - 1) / BLK)).collect();
        blocks.sort_unstable(); blocks.dedup();

        let mut next_l3 = PT_L3_BASE;
        for bi in blocks {
            let (l3_host, l3_len) = alloc_pages(GRANULE);
            let l3 = unsafe { std::slice::from_raw_parts_mut(l3_host as *mut u64, 2048) };
            let base = bi * BLK;
            for (j, e) in l3.iter_mut().enumerate() {
                *e = (base + (j as u64) * GRANULE as u64) | ATTR_DATA | DESC_PAGE;
            }
            assert!(next_l3 + GRANULE as u64 <= PT_L3_CEIL,
                "build_tables: too many exec blocks; L3 window 0x{PT_L3_BASE:x}..0x{PT_L3_CEIL:x} exhausted");
            l2[bi as usize] = next_l3 | DESC_TABLE;
            backings.push(Backing { host: l3_host, ipa: next_l3, len: l3_len });
            // overwrite pages this block's exec ranges cover
            for &(va, len, attr) in exec {
                let s = va.max(base);
                let e = (va + len).min(base + BLK);
                let mut p = s & !(GRANULE as u64 - 1);
                while p < e {
                    l3[((p - base) / GRANULE as u64) as usize] = p | attr | DESC_PAGE;
                    p += GRANULE as u64;
                }
            }
            next_l3 += GRANULE as u64;
        }
        PT_L2_IPA
    }
}
```
In `load`, after the segment/stack/trampoline maps and before setting registers, build the exec range list (the EL1 trampoline + every executable guest segment), build + stage-2-map the tables, and switch the sysregs (replace the `SCTLR_EL1 <- 0x30d00800 (MMU off)` line):

### Task 4: `forward_and_diff` forwarded-count clamp (debt #1 — memory safety)

M1 forwards a buffer-filling syscall's byte count to the host kernel **unchanged**: a `read`/`pread` with a count larger than the destination buffer's backing has the kernel write past that backing (a real host-memory overwrite). The fix is to clamp the **forwarded count argument** (`x2`) to the destination buffer's available bytes, so the kernel can never write past the backing. Real dyld issues large variable reads, so this is now reachable.

**Note on the mechanism:** the snapshot/diff *window* (`avail.min(PTR_WINDOW_CAP)`) is left exactly as M1 has it — do NOT clamp the snapshot by `x2`, because `x2` is only a byte count for `read`/`pread`; for e.g. `fstat` (`x1`=statbuf, `x2`=unused) that would under-snapshot the buffer and miss the kernel's write, regressing M1. The clamp applies ONLY to the forwarded count of the known buffer-filling syscalls.

**Verified facts about `/usr/lib/dyld` (arm64e) on this host — the design depends on them:**
- It is a **PIE `MH_DYLINKER`** whose `__TEXT` is at **vmaddr 0x0** (segments span 0x0..~0x140000). pub fn slice_arm64e(fat: &[u8]) -> &[u8] {
    let magic = u32::from_le_bytes(fat[0..4].try_into().unwrap());
    if magic == 0xfeed_facf { return fat; }                         // already a thin 64-bit Mach-O
    let be32 = |o: usize| u32::from_be_bytes(fat[o..o+4].try_into().unwrap());
    let fatmagic = be32(0);
    let is64 = fatmagic == retrace_arch::FAT_MAGIC_64;
    assert!(fatmagic == retrace_arch::FAT_MAGIC || is64, "not a fat binary");
    let nfat = be32(4) as usize;
    let (entry_sz, off_field) = if is64 { (32usize, 16usize) } else { (20usize, 8usize) };
    for i in 0..nfat {
        let e = 8 + i * entry_sz;                                   // fat_arch[i]
        let cputype = be32(e);
        let cpusubtype = be32(e + 4);
        if cputype == retrace_arch::CPU_TYPE_ARM64
            && (cpusubtype & 0x00ff_ffff) == retrace_arch::CPU_SUBTYPE_ARM64E {
            let (off, size) = if is64 {
                (u64::from_be_bytes(fat[e+off_field..e+off_field+8].try_into().unwrap()) as usize,
                 u64::from_be_bytes(fat[e+off_field+8..e+off_field+16].try_into().unwrap()) as usize)
            } else {
                (be32(e + off_field) as usize, be32(e + off_field + 4) as usize)
            };
            return &fat[off..off + size];
        }
    }
    panic!("no arm64e slice in fat binary");
}
```

pub const DYLD_BASE: u64 = 0x1_4000_0000;      // 5 GiB: above exe (~4 GiB), below mmap (8 GiB)
const DYN_STACK_TOP:  u64 = 0x0020_0000;       // 2 MiB (block 0, RW+non-exec by default, below PT_L3_BASE)
const DYN_STACK_SIZE: u64 = 0x0004_0000;       // 256 KiB

impl Box_ {
    pub fn sp(&self) -> u64 { self.vcpu.get_sys(sysreg::SP_EL0).unwrap() }

    pub fn load_dynamic(exe: &Loaded, dyld: &Loaded, argv0: &str) -> Box_ {
        let vm = Vm::create().expect("hv_vm_create");
        let vcpu = Vcpu::create(&vm).expect("hv_vcpu_create");
        let mut backings = Vec::new();
        // (reuse load's `map` closure verbatim)
        for s in &exe.segments  { /* map at */ s.vaddr; }
        for s in &dyld.segments { /* map at */ s.vaddr + DYLD_BASE; }
        // dynamic stack (anon, zero-filled)
        /* map */ (DYN_STACK_TOP - DYN_STACK_SIZE) .. DYN_STACK_TOP, size DYN_STACK_SIZE;
        // trampoline (16 slots * 0x80, each `hvc #0`) at TRAMPOLINE_IPA — same as load
        // start stack (writes into the stack backing, returns guest SP)
        let sp = Self::build_start_stack(backings.last_stack(), argv0);
        // W^X exec ranges
        let mut exec = vec![(TRAMPOLINE_IPA, 0x800u64, ATTR_TRAMP)];
        for s in &exe.segments  { if s.exec { exec.push((s.vaddr,             s.memsz as u64, ATTR_CODE)); } }
        for s in &dyld.segments { if s.exec { exec.push((s.vaddr + DYLD_BASE, s.memsz as u64, ATTR_CODE)); } }
        let pt_start = backings.len();
        let ttbr0 = Self::build_tables(&mut backings, &exec);
        for bk in &backings[pt_start..] { vm.map(bk.host, bk.ipa, bk.len, MemFlags::RWX).expect("hv_vm_map (pt)"); }
        Self::set_pac_keys(&vcpu);
        vcpu.set_sys(sysreg::VBAR_EL1, TRAMPOLINE_IPA).unwrap();
        vcpu.set_sys(sysreg::MAIR_EL1,  MAIR_EL1_V).unwrap();
        vcpu.set_sys(sysreg::TCR_EL1,   TCR_EL1_V).unwrap();
        vcpu.set_sys(sysreg::TTBR0_EL1, ttbr0).unwrap();
        vcpu.set_sys(sysreg::SCTLR_EL1, SCTLR_MMU_ON).unwrap();
        vcpu.set_sys(sysreg::SP_EL0, sp).unwrap();
        vcpu.set_reg(reg::CPSR, 0).unwrap();                        // EL0t
        vcpu.set_reg(reg::PC, dyld.entry + DYLD_BASE).unwrap();     // dyld's SLID entry
        Box_ { vm, vcpu, backings, mmap_next: MMAP_BASE }
    }

    // Build the XNU start stack in the (already-mapped, zeroed) stack backing; return the guest SP.
    // Layout at SP (low->high): argc, argv[0..argc], NULL, envp..., NULL, apple..., NULL, then C-strings.
    // First cut — the exact apple[]/env set dyld requires is discovered empirically in Task 9.
    fn build_start_stack(stack: &Backing, argv0: &str) -> u64 {
        let base_ipa = stack.ipa;
        let top = stack.ipa + stack.len as u64;
        let strings: [Vec<u8>; 3] = [
            { let mut v = argv0.as_bytes().to_vec(); v.push(0); v },                 // argv[0]
            b"DYLD_SHARED_REGION=private\0".to_vec(),                                 // envp[0]
            { let mut v = format!("executable_path={argv0}").into_bytes(); v.push(0); v }, // apple[0]
        ];
        let mut p = top;
        let mut addr = [0u64; 3];
        for (i, s) in strings.iter().enumerate() {
            p -= s.len() as u64;
            addr[i] = p;
            unsafe { std::ptr::copy_nonoverlapping(s.as_ptr(), stack.host.add((p - base_ipa) as usize), s.len()); }
        }
        let words = [1u64, addr[0], 0, addr[1], 0, addr[2], 0];     // argc, argv, NULL, envp, NULL, apple, NULL
        let sp = (p - words.len() as u64 * 8) & !15u64;             // 16-byte aligned
        for (i, w) in words.iter().enumerate() {
            let off = (sp - base_ipa) as usize + i * 8;
            unsafe { std::ptr::copy_nonoverlapping(w.to_le_bytes().as_ptr(), stack.host.add(off), 8); }
        }
        sp
    }
}
```

## M2 → M3 boundary

M3 is instruction-exact positioning — single-step counting from landmarks, interval snapshots, and hardware breakpoints — so replay can stop at an exact instruction across record and replay. The MMU, PAC, loader, and full syscall/mach surface built here carry forward. Items this milestone leaves for later:

- **Stack/`apple[]` minimalism.** T7 builds the smallest start stack dyld accepts; a real interpreter (M6) may need more `apple[]` entries (entropy, `dyld_file=`, `executable_file=`, `main_stack=`). Widen as programs demand; the oracle flags a miss.
- **`mprotect` is fidelity-only.** Stage-2 stays RWX; a program relying on a real protection fault won't get one. Fine for benign M2/M3 targets; revisit if a guest depends on `PROT_NONE` guard-page faults.
- **Whole-cache mapping cost.** File-backed mmap `pread`s the whole requested extent eagerly and records it as `writes`; a large interpreter could make traces big. Compression is deferred post-v1 (master spec); measure before optimizing.
- **Commpage/`CNTVCT` instrumentation** is only added in T9 if dyld trips it; systematic read-site handling is M5's hardening.

## Risk register

1. **Unknown count of dyld special cases (schedule).** T9 is discovery, not construction; the number of mach traps/nondeterministic inputs dyld startup needs is not known until it runs. *Mitigation:* the oracle bounds every miss to a named, seed-reproducible failure; T9 front-loads the harness so each iteration is minutes. If the tail is long, ship the handlers found and pin the rest as follow-ups — the gate (`hello_dyn` green) is a fixed target.
2. **`MAP_FIXED` cache address outside the identity map.** The default RW+non-exec blocks identity-cover the whole 36-bit space, but if dyld maps the cache above that via `MAP_FIXED`, no block covers it, and any executable cache/dylib page needs an RO+exec promotion regardless. *Mitigation:* the observed arm64e cache sits ~6 GiB (block 195, well inside range); if a build differs, widen the map — a localized change in `build_tables`. Exec mappings from dyld are promoted to RO+exec pages by `guest_mmap_file` (T8), never left as writable data.
3. **PAC key/layout determinism.** Any signing that depends on state we don't fix diverges. *Mitigation:* fixed keys + identity VA==IPA + fixed MMU layout; the oracle flags residual nondeterminism; PAC can be disabled (`EnIA=0`, spike-verified) to bisect a suspected PAC divergence.
4. **Trace-format churn.** T5 bumps the format (`err` field). *Mitigation:* the magic/version byte already rejects stale traces loudly (M1 t2); no silent misread.
5. **retrace-box growth.** The crate gains MMU/PAC/loader/forward logic. *Mitigation:* the T2 note mandates a module split past ~450 lines, keeping `Box_`'s public surface stable.
6. **SPTM re-panic.** Any new `hv_vm_map` on a non-anon page re-panics the host. *Mitigation:* the Global-Constraints hard rule; every mapping site in this plan takes an anon buffer; code review greps for `hv_vm_map` + file descriptors.

## Non-goals / explicitly deferred

- Any shared-cache format parsing (we run real dyld).
- Multi-threaded startup, signals, positioning, the debugger seam (M3+).
- Enforced `mprotect` protections / `PROT_NONE` guard-page faults.
- Recording untrusted/adversarial binaries at full hardening — the write-extent clamp (T4) is the one memory-safety fix pulled forward because it is trivially reachable by real reads.
- Cross-machine / cross-OS trace portability (same-chip-class, pinned build; unchanged from M1).
- Trace compression (deferred post-v1 per the master spec).

## Open questions for implementation planning

- **PAC enabled vs. disabled for first bring-up (T9).** Leaning enabled (spike shows it works; disabling risks masking a real determinism bug); flip to `EnIA=0` only to bisect a suspected PAC divergence.
- **Exact `apple[]`/env minimum (T7/T9).** Determined empirically against real dyld; the oracle flags anything missing. Start with `DYLD_SHARED_REGION=private` + executable path.
- **File-backed mmap eager vs. lazy (T8).** Eager whole-extent `pread` chosen (simple, deterministic); revisit only if cache-sized mappings make traces unwieldy.
- **Where the raw-`svc` shim lives (T5).** In `retrace-box` via `core::arch::asm!` (chosen), keeping the forwarding path under the box's control rather than widening `hv-sys`.
